SCREEN DEPENDENCIES
===================

LoginScreen
  ├─ useAuth (for login function)
  ├─ authService (authentication)
  └─ api (HTTP calls)

HomeScreen
  ├─ api (fetch stats and delivery)
  ├─ useAuth (get user info)
  └─ useNavigation (navigate to delivery)

RoutesScreen
  ├─ api (fetch routes)
  ├─ useNavigation (navigate to route detail)
  └─ useFocusEffect (refresh on tab focus)

RouteDetailScreen
  ├─ api (fetch route details)
  ├─ useRoute (get routeId param)
  ├─ useNavigation (navigate back)
  └─ Linking (native maps)

DeliveryScreen
  ├─ api (fetch and update delivery)
  ├─ useRoute (get deliveryId param)
  ├─ ImagePicker & Camera (POD photos)
  └─ useNavigation (navigate back)

ProfileScreen
  ├─ useAuth (user info, logout)
  ├─ api (fetch profile)
  └─ useNavigation (redirect after logout)


SERVICE DEPENDENCIES
====================

api.ts (ApiClient)
  └─ SecureStore (token management)

auth.ts (AuthService)
  ├─ api (HTTP calls)
  └─ SecureStore (token & user storage)

location.ts (LocationService)
  ├─ expo-location (GPS)
  ├─ api (HTTP location updates)
  └─ socket.io-client (real-time updates)

useAuth.ts (Hook)
  ├─ authService (auth logic)
  └─ React.Context (state management)

DEVELOPMENT WORKFLOW
====================

1. Clone/Create Project
   └─ npm install

2. Configure Environment
   └─ cp .env.example .env
   └─ Edit .env

3. Start Development
   └─ npm start
   └─ Press 'i' (iOS) or 'a' (Android)

4. Code & Test
   └─ Make changes
   └─ Hot reload (auto)
   └─ Test features

5. Build & Deploy
   └─ npm run typecheck
   └─ npm run lint
   └─ eas build --platform ios/android


BUILD TARGETS
=============

Development:
  └─ npm start (Expo CLI)

Staging:
  └─ eas build --platform ios
  └─ eas build --platform android

Production:
  └─ eas build --platform ios --profile production
  └─ eas build --platform android --profile production
  └─ eas submit (to app stores)


SUPPORTED PLATFORMS
===================

Android:
  └─ Minimum: Android 5.0+ (API 21)
  └─ Target: Android 14+ (API 34)
  └─ Arch: arm64-v8a, armeabi-v7a

iOS:
  └─ Minimum: iOS 13+
  └─ Target: iOS 17+
  └─ Arch: arm64


PERMISSIONS REQUIRED

Camera:
