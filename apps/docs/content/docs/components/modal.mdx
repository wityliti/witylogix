# Modal

The Modal component displays content in a dialog box overlaid on the main page, with overlay dismiss, keyboard support, and footer actions.

## Import

```typescript
import {
  Modal,
  ModalHeader,
  ModalTitle,
  ModalContent,
  ModalFooter
} from "@/components/ui"
```

## Basic Usage

```tsx
import { useState } from "react"

const [isOpen, setIsOpen] = useState(false)

<>
  <Button onClick={() => setIsOpen(true)}>Open Modal</Button>

  <Modal isOpen={isOpen} onClose={() => setIsOpen(false)}>
    <ModalHeader>
      <ModalTitle>Modal Title</ModalTitle>
    </ModalHeader>
    <ModalContent>
      <p>Modal content goes here</p>
    </ModalContent>
  </Modal>
</>
```

## Structure

| Component | Purpose | Notes |
|-----------|---------|-------|
| **Modal** | Container | Manages overlay and dialog |
| **ModalHeader** | Top section | Contains title and close button |
| **ModalTitle** | Heading | h2 element |
| **ModalContent** | Main area | Primary content |
| **ModalFooter** | Bottom section | Action buttons |

## Sizes

Modal supports three predefined sizes:

```tsx
<Modal size="sm" isOpen={isOpen} onClose={onClose}>
  {/* Content */}
</Modal>

<Modal size="md" isOpen={isOpen} onClose={onClose}>
  {/* Content */}
</Modal>

<Modal size="lg" isOpen={isOpen} onClose={onClose}>
  {/* Content */}
</Modal>
```

### Size Details

| Size | Max Width | Use Case |
|------|-----------|----------|
| **sm** | 384px | Confirmations, alerts |
| **md** | 512px | Forms, default dialogs |
| **lg** | 768px | Complex forms, layouts |

## Props Table

### Modal

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isOpen` | boolean | - | Control modal visibility |
| `onClose` | function | - | Callback when modal closes |
| `size` | "sm" \| "md" \| "lg" | "md" | Modal width |
| `closeOnEscape` | boolean | true | Close on Escape key |
| `closeOnOverlay` | boolean | true | Close on overlay click |

### ModalContent

| Prop | Type | Default | Description |

## Behavior

### Escape Key Handling

By default, pressing Escape closes the modal:

```tsx
<Modal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  closeOnEscape={true}
>
  {/* Content */}
</Modal>
```

Disable with `closeOnEscape={false}` for important operations.

### Overlay Dismiss

Click the overlay to close:

```tsx
<Modal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  closeOnOverlay={true}
>
  {/* Content */}
</Modal>
```

Disable with `closeOnOverlay={false}` for forms or critical actions.

## Styling

### Custom Width

```tsx
<Modal isOpen={isOpen} onClose={onClose} className="max-w-2xl">
  {/* Content */}
</Modal>
```

### Full Height Modal

```tsx
<Modal isOpen={isOpen} onClose={onClose} className="min-h-full">

</Modal>
```

## Accessibility

- Focus trapping within modal
- Semantic HTML (dialog role)
- Keyboard navigation (Escape, Tab)
- ARIA labels and descriptions
- Focus restoration on close
- Overlay with scrim for context
- Clear close button in header

## Best Practices

1. Use descriptive titles
2. Keep content focused and concise
3. Place primary action on the right in footer
4. Disable overlay dismiss for critical forms
5. Provide clear cancel option
6. Test keyboard navigation
7. Ensure sufficient contrast
8. Avoid nested modals
9. Handle loading states in forms
10. Restore focus after closing
