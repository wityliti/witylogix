# Webhooks

Webhooks allow you to receive real-time notifications about shipment events. Instead of polling the API, we'll push updates directly to your application.

## How Webhooks Work

1. You register a webhook endpoint in your dashboard
2. When an event occurs (e.g., shipment delivered), we send an HTTP POST to your endpoint
3. Your application processes the event
4. You respond with HTTP 200 to confirm receipt

## Webhook Events

Available events:

| Event | Description |
|---|---|
| `shipment.created` | Shipment was created |
| `shipment.picked_up` | Shipment was picked up by driver |
| `shipment.in_transit` | Shipment is in transit |
| `shipment.delivered` | Shipment was delivered |
| `shipment.failed` | Delivery attempt failed |
| `shipment.cancelled` | Shipment was cancelled |

## Webhook Payload

Every webhook POST includes a JSON body with the event type, timestamp, and event-specific data:

```json
{
  "id": "evt_2xK9mN4pQ7",
  "event": "shipment.delivered",
  "created_at": "2026-03-10T14:32:00Z",
  "data": {
    "shipment_id": "shp_8vL3nR2wM5",
    "status": "delivered",
    "delivered_at": "2026-03-10T14:31:45Z",
    "recipient": "Jane Doe",
    "proof_of_delivery": "https://cdn.witylogix.com/pod/shp_8vL3nR2wM5.jpg"
  }
}
```

## Registering a Webhook

1. Go to **Settings → Webhooks** in your dashboard
2. Click **Add Webhook**
3. Enter your endpoint URL (must be HTTPS)
4. Select events to subscribe to
5. Click **Create**

Or register programmatically via the API:

## Webhook Signature Verification

We sign all webhooks using HMAC-SHA256. Always verify the signature before processing events.

<CodeTabs tabs={[
  {
    label: "Node.js",
    icon: "🟢",
    filename: "verify.ts",
    code: `import crypto from 'crypto';

function verifyWebhookSignature(
  body: string,
  signature: string,
  secret: string
): boolean {
  const expected = crypto
    .createHmac('sha256', secret)
    .update(body)
    .digest('hex');

  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expected)
  );
}`
  },
  {
    label: "Python",
    icon: "🐍",
    filename: "verify.py",
    code: `import hmac
import hashlib

def verify_webhook_signature(
    body: bytes,
    signature: str,
    secret: str,
) -> bool:
    expected = hmac.new(
        secret.encode(),
        body,
        hashlib.sha256,
    ).hexdigest()

    return hmac.compare_digest(signature, expected)`
  }
]} />

## Retries

We retry failed webhooks with exponential backoff:

| Attempt | Delay |
|---|---|
| 1st | Immediately |
| 2nd | 5 minutes |
| 3rd | 30 minutes |
| 4th | 2 hours |
| 5th | 24 hours |

Respond with HTTP 200 to prevent retries. After 5 failed attempts, the webhook is marked as **disabled** and you'll receive an email notification.

## Best Practices

1. **Respond quickly** — Return HTTP 200 within 5 seconds. Queue heavy processing for async handling.
2. **Verify signatures** — Always validate `X-Witylogix-Signature` before trusting the payload.
3. **Handle duplicates** — Use the `id` field to deduplicate events. We guarantee at-least-once delivery.
4. **Process asynchronously** — Offload database writes and email sends to a background queue.
5. **Monitor failures** — Set up alerts for webhook delivery failures in your dashboard.
