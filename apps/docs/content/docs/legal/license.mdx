## License Overview

Witylogix is licensed under the **GNU Affero General Public License v3.0 (AGPL-3.0)**. This is a strong copyleft license designed to ensure that software remains free and open source, even when it is used to provide services over a network.

The AGPL-3.0 builds on the GPL-3.0 by adding a requirement that if you run a modified version of the software as a network service, you must make the source code available to users of that service.

## What You Can Do

- Use Witylogix for any purpose (personal, commercial, non-profit)
- Modify the source code to fit your needs
- Self-host on your own infrastructure
- Distribute modified versions (under AGPL-3.0)
- Build integrations and extensions

## What You Must Do

- Make source code available if you distribute or offer as a network service
- License modifications under AGPL-3.0
- Include copyright and license notices
- State changes you made to the code

## Self-Hosting

If you self-host Witylogix for your own business (not offering it as a service to others), you can use it freely. The AGPL-3.0 network clause applies only if you make the software available to third parties over a network as a service.

For example, running Witylogix internally for your own operations does not trigger the source code sharing requirement. However, if you modify Witylogix and offer it as a hosted platform to external customers, those customers have the right to request the source code of your modified version.

## Commercial Licensing

For organizations that need a commercial license (for example, to offer Witylogix as a SaaS product without sharing source code), commercial licensing options are available.

Contact [connect@wityliti.io](mailto:connect@wityliti.io) for commercial licensing inquiries.

## Third-Party Dependencies

Witylogix includes third-party open source libraries, each with their own licenses. These dependencies are managed through the package manager and their licenses can be found in the respective `package.json` files and `node_modules` directories throughout the monorepo.
