===============================================================================
                           INTEGRATION STEPS
===============================================================================

1. INSTALL DEPENDENCIES:
   pnpm add next-intl date-fns
   pnpm add -D @types/date-fns glob

2. UPDATE next.config.ts:
   - Add: import createNextIntlPlugin from 'next-intl/plugin'
   - Wrap: const withNextIntl = createNextIntlPlugin('./src/i18n/request.ts')
   - Export: export default withNextIntl({ ... })

3. UPDATE Root Layout (src/app/layout.tsx):
   - Import: LocaleProvider, getMessages
   - Add params: Promise<{ locale: string }>
   - Validate locale against supportedLocales
   - Wrap content in LocaleProvider

4. REPLACE HARDCODED TEXT:
   - Import useTranslations from 'next-intl'
   - Call: const t = useTranslations('namespace')
   - Use: {t('key.path')}

5. ADD LANGUAGE SWITCHER (Optional):
   - Import LanguageSwitcher component
   - Get locale: const locale = useLocale()
   - Render: <LanguageSwitcher currentLocale={locale as any} />

6. VALIDATE SETUP:
   - Run: npm run dev
   - Visit: /en, /es, /fr
   - Check DevTools for NEXT_LOCALE cookie
