Critical Blockers (Must Fix Before Launch)

  • 1. Build fails — 3 compile errors
    Duplicate formatCurrency declaration, missing @/components/ui/loading module (3 pages), duplicate useParams imports (2 pages).
    customers/page.tsx, dispatch/couriers/page.tsx, drivers/performance/page.tsx, supply-chain/inventory/page.tsx, integrations/marketplace/[providerId]/page.tsx, invoices/[id]/page.tsx
  • 2. Auth is a UI shell — hardcoded demo credentials
    demo@witylogix.com / demo123 bypass lets anyone in. Tokens in localStorage = XSS risk. Middleware doesn't validate tokens, just checks cookie exists.
    lib/auth-context.tsx:113, middleware.ts:45-52
  • 3. JWT not attached to API calls
    API client has JWT auth commented out. Backend requireAuth middleware would reject all requests with 401 in production.
    lib/api.ts:44-45
  • 4. No code splitting — ~1.1MB monolithic bundle
    95% of code loads on first page hit. Dashboard layout marked "use client" forces entire app to client-render. Recharts (200KB) always loaded.
    app/(dashboard)/layout.tsx, next.config.ts
  • 5. TypeScript errors suppressed
    ignoreBuildErrors: true in next.config.ts masks 2,186+ type errors. Real issues hidden.
    next.config.ts
  • 6. Integration pages are non-functional
    All 30+ integration category pages use hardcoded mock data. No actual OAuth flows or provider API connections exist.
    app/(dashboard)/integrations/*/page.tsx
  • 7. 24 console.log statements in production code
    Debug logging throughout team, mobile-config, invoices, dispatch, CRM, and admin pages.
    team/page.tsx, invoices/[id]/page.tsx, dispatch/page.tsx, crm/page.tsx, etc.
