# WityLogix v1.0.0-beta

**WityLogix v1.0.0-beta** is the first public beta of the open-source delivery management platform for e-commerce merchants. Self-host your entire last-mile logistics stack — from zone-based checkout pricing to real-time driver tracking and proof of delivery — without per-transaction fees.

## What's included

### Core platform

- **Order and delivery management** — full order lifecycle with an 8-column Kanban board, bulk actions, and status-driven workflows
- **Route optimization** — multi-stop routing via OSRM and OR-Tools (nearest-neighbour + 2-opt), with Mapbox, Google Maps, HERE, and GraphHopper as optional providers; bring your own API key (BYOK)
- **Real-time tracking** — driver location streaming over Socket.io with a customer-facing Leaflet map; SSE fallback for WebSocket-unavailable environments
- **ETA prediction** — LightGBM-based ETA model using historical delivery data, traffic signals, and route geometry
- **Multi-tenant isolation** — PostgreSQL Row-Level Security (RLS) enforced at the database layer; every query is tenant-scoped by default

### Integrations

- **Shopify App** — embedded admin app, checkout UI extension (delivery date/time-slot picker, < 64 KB), Carrier Service API for live delivery rates at checkout
- **WooCommerce plugin** — shipping method integration with zone-based pricing and live rate calculation

### Driver app

- **React Native** (iOS + Android) — background GPS tracking, delivery workflow, and proof of delivery (photo capture, signature, barcode scan)

### Merchant dashboard

- **Admin dashboard** — order management, driver management, zone editor (PostGIS polygon drawing), route planner, live dispatch command center, analytics, campaign engine, and returns/RMA management
- **Billing and subscriptions** — plan management, proration, quota enforcement, and invoice generation with PDF export

### Self-hosting

- **Railway-ready** — `railway.toml` included; deploy API, dashboard, and docs apps in minutes
- **Docker Compose** — production stack with Postgres+PostGIS, Redis, API, dashboard, Shopify app, worker, and Nginx; health checks and graceful shutdown included
- **Prisma migrations** — automated schema migrations on startup; rollback-safe with compensating transactions
- **Demo seed script** — `scripts/seed-demo.ts` populates a working tenant with sample orders, drivers, and zones

---

## Known limitations

- **BFS (Buy from Stock) certification** — in progress; Shopify app is not yet available on the Shopify App Store
- **Single-region deployment** — multi-region replication and global edge routing are not yet supported
- **WooCommerce and headless storefronts** — integrations are functional but not yet covered by automated end-to-end tests
